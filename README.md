# unthinkable

A white page with black text. The archive is generated by the Unthinkable engine on the Mac mini and published through GitHub Pages.

The handwriting is a local font built from the original pen-stroke alphabet used on tiago.lol. Five drawings of each character and contextual alternates vary the lettering. Uppercase and lowercase drawings are randomly mixed within words, independently of the source character's case. Proportional spacing adds irregular gaps in the words; circuit rows use a fixed grid. Each post has a stable, seeded mix of size, tilt, margins, and whitespace.

Posts remain native Unicode text. Selecting and copying preserves the original spaces, line breaks, accents, and circuit symbols; no clipboard handler or invisible duplicate is needed. The design does not change `posts.json` or the publishing engine. Long circuits can scroll horizontally on small screens.

To rebuild the bundled font after editing `scripts/pen-alphabet.json`:

```sh
python3 -m venv .font-env
.font-env/bin/pip install -r scripts/font-requirements.txt
.font-env/bin/python scripts/build-handwriting.py
```

Serve this directory with any static server to preview the page.
